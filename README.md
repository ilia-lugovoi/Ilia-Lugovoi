Data / BI Analyst со бэкграундом в операционной и экономической аналитике (Яндекс) и опытом построения end-to-end решений для бизнеса.

<br>

**Ключевой фокус:** Проектирование аналитических витрин данных, автоматизация отчетности и исследование бизнес-процессов для принятия управленческих решений.

**Полный цикл (End-to-End):** От сбора и очистки сырых данных (Python, SQL) и моделирования (dbt, PostgreSQL/ClickHouse) до создания интерактивных BI-дашбордов (Power BI, Superset, DataLens).

**Доменная экспертиза:** E-commerce, операционная аналитика, CRM, продажи, логистика, управление запасами и финансовые метрики
